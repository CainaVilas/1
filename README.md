# Tela de Login com PySimpleGUI

Aplicação simples desenvolvida em Python utilizando a biblioteca **PySimpleGUI** para demonstrar a criação de uma interface gráfica de autenticação.

## Funcionalidades

- Interface gráfica de login
- Entrada de usuário e senha
- Campo de senha mascarado
- Opção para salvar o login
- Validação básica de credenciais
- Encerramento da aplicação ao fechar a janela

## Tecnologias

- Python 3
- PySimpleGUI

## Como executar

1. Instale a biblioteca:
   ```bash
   pip install PySimpleGUI
   ```

2. Execute o arquivo:
   ```bash
   python login.py
   ```
